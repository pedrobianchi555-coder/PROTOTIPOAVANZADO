# 🔧 Carro H - Guía Lineal DIY

Proyecto independiente para visualizar y planificar la construcción de un **Carro H** (guía lineal casera) para esmeril angular.

## 📦 Contenido

- **CarroHProject.tsx** - Componente principal con interfaz completa (4 pestañas)
- **CarroH3D.tsx** - Visualizador 3D interactivo usando Three.js
- **carroHMateriales.ts** - Lista de materiales y especificaciones técnicas
- **index.ts** - Punto de entrada para importar componentes

## 🚀 Uso

```tsx
import { CarroHProject } from '../projects/CarroH';

// En tu componente React
<CarroHProject />
```

## 📋 Características

### 🎯 Visor 3D
- Modelo 3D interactivo con Three.js y React Three Fiber
- Estructura completa del Carro H con todos los componentes
- Controles: rotar, zoom, pan
- Iluminación realista y materiales metálicos

### 📦 Lista de Materiales
- 12 componentes con especificaciones detalladas
- Cantidades, medidas y precios
- Cálculo automático de costo total

### 📏 Especificaciones
- Dimensiones: 30cm × 50cm × 25cm
- Componentes: 4 tubos, 16 rodillos, 32 pernos
- Tolerancia de corte: ±2 mm
- Materiales que corta: porcelanato, baldosas, hierro

### 📖 Instrucciones
- 10 pasos de ensamblaje
- Consejos de fabricación
- Advertencias de seguridad

## 🔧 Especificaciones Técnicas

**Estructura:**
- Tubos cuadrados 1½" x 1½" (4 piezas de 30cm)
- 16 rodillos de precisión distribuidos
- Pernos y tuercas M8 para ajuste

**Rendimiento:**
- Tolerancia: ±2 mm en cortes rectos
- Peso aproximado: 15-18 kg
- Velocidad variable según motor del esmeril

**Materiales que puede cortar:**
- Porcelanato
- Baldosas cerámicas
- Láminas de hierro
- Acero fino
- Vidrio
