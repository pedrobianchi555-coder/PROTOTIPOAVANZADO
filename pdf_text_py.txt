Configurations  
Copy the following template to a file named .cle.json5 in your home directory.
Path for Unix-like OS: ~/.cle.json5
Path for Windows:  %userprofile%\.cle.json5
{
  // Logs directory.
  // $HOME redirects to the current user's home directory.
  // $TMP redirects to the operating system's default directory for 
temporary files
  LOGS_PATH: '$TMP/cle/logs',
 
  // When a file size becomes higher than this value it will rotate it 
(its possible that 
  // the worker check the file after it actually pass the limit) . You 
can specify the
  // unit at then end: 10G, 10M, 10K
  LOG_MAX_SIZE: '1G',
 
  // Enable compression via gzip for all rotated logs
  LOG_COMPRESS: true,
 
  // This cron is used to a force rotate when executed. We are using 
node-schedule to
  // schedule cron, so all valid cron for node-schedule is valid cron 
for this option. 
  LOG_ROTATE_INTERVAL: '0 0 * * *',
Usage  
Note: Under Windows, you must run the command as an administrator.
 
  // Duration per file for saving buffers. (ms)
  BUFFERS_DURATION_PER_FILE: 600000,
 
  // Duration per file for saving records. (ms)
  RECORDS_DURATION_PER_FILE: 600000,
 
  // Network Interface
  // eg. 'eth0', 'wlan'
  NETWORK_INTERFACES: ['eth0'],
 
  // HTTP API Port
  HTTP_API_PORT: 44444,
 
  // UDP API Port
  UDP_API_PORT: 55555,
 
  // Beacon Lifetime

  MAX_NUMBER_OF_UDP_SUBSCRIBERS: 1,
}
